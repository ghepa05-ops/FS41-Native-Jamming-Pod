# FS-41 Native Jamming Pod

Adds the native Nuclear Option Radar Jamming Pod to the Aryx FS-41 Eclipse.

The mod uses the game's existing `JammingPod1` weapon and native ECM/jamming logic. It does not implement a custom jammer.

## Requirements

- Nuclear Option
- BepInEx
- Blueprinter
- Aryx FS-41 Eclipse

## Installation

Copy the contents of the `BepInEx` directory into the Nuclear Option game directory.

The resulting path should be:

BepInEx/plugins/FS41JammingPod/FS41JammingPod.dll

## Available hardpoints

The Radar Jamming Pod is added to:

- Centreline Pylon
- Wing Glove Pylons
- Wing Pylons
